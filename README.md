# Proyecto DevSecOps - Grupo 2

## Descripción
API REST desarrollada con Node.js y Express para la gestión de tareas.

## Objetivo
Demostrar la integración de prácticas de seguridad en el ciclo de desarrollo de software.

## Funcionalidades
- Consultar tareas.
- Crear tareas.
- Actualizar tareas.
- Eliminar tareas.
- Validar información recibida.

## Tecnologías
- Node.js
- Express
- GitHub
- GitHub Actions
- Semgrep
- Gitleaks
- Trivy

## Ejecución

Instalar dependencias:
npm install

Iniciar aplicación:
npm start

Servidor:
http://localhost:3000
